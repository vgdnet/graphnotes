## 1. Назначение

Согласованное продуктовое ТЗ: для кого продукт, роли, функции, границы MVP,
критерии приёмки. Реализация и стек — не здесь (`MASTER_CONTEXT`, стадии).

## Куда смотреть по задаче

- **Локальный склад у нас** (ТЗ 2.61–2.63): GitHub, git, позже Dropbox / Google Drive — только **источники**. Продукт **копирует** `.md` в локальное хранилище (личное и опубликованная общая). Граф, карточки и Differ читают копию. → [vision.md](vision.md), [principles.md](principles.md) §3.1–3.4, [functional.md](functional.md) §6.2–6.3
- **Настройки аккаунта (`/user`), договор, свой git (опция), почта, Theme Switcher светлая/тёмная** → [user-settings.md](user-settings.md)
- **Текст договора автора, лицензия карточек (WTFPL) и ПО (AGPL-3.0)** → [user-settings.md](user-settings.md) §5.5.3, [roles.md](roles.md) §5.4
- **Карта адресов** (ТЗ 2.58/2.59; опечатка `/seach` → `/search`) →
  [search-and-card.md](search-and-card.md) §6.5.2.
  `/card` — стартовая карточка admin; `/card/{путь}` — карточка;
  `/queue` — очередь editor’а; `/user` — настройки; `#/users/{uuid}` —
  публичная карточка человека (ТЗ 2.60); `/offer` — мои
  предложения; `/graph` — общий холст; `/search` — поиск; `/my_graph` —
  личный слой графа; `/contribution` — мой вклад; `/differ` —
  Отличающиеся. `/` → `/graph`. 2.57 (`/user` = карточка человека,
  `/offer` = общая очередь) — ошибка, снято. **Поставлено в 2.59–2.60**.
- **Стартовый граф (`/graph`) и уровни доступа к ризоме** → [access.md](access.md) §5.6
- **«Два графа» и вид «ризома автора»** → [access.md](access.md) §5.6.4
  (общая + свой overlay на одном графе; закрытый срез — отдельный вид после
  уровня; «загрузить» = открыть в приложении, не скачать файлы)
- **Слои «ваша часть ризомы» / «ваша личная ризома»** → [access.md](access.md) §5.6.2, [functional.md](functional.md) §6.3.2, [terms.md](terms.md)
- **Поиск и страница карточки** → [search-and-card.md](search-and-card.md)
  (`/search` — каталог; `/card/{путь}`: слой в адресе не пишется; править
  можно только свою; тот же путь в личном и в общей → стопка: ризома сверху,
  своя снизу, даже при полном совпадении; ниже офер в `/differ`. Hash
  `#/card/personal:` — переходный, не канон. **2.59:** `/card/{путь}`
  без слоя в адресе; один путь в обоих слоях — стопка (ризома сверху,
  своя снизу) + офер в `/differ`. `#/card/personal:` остаётся переходным
  для тонкого редактора)
- **Весь граф и локальный граф** → [functional.md](functional.md) §6.5.1
  (вид как в Obsidian: выбранный узел и глубина 1–4; «Показать всё»)
- **Кто такой автор и закрытый срез (платный уровень доступа)** → [roles.md](roles.md) §5.4
- **Admin: пользователи, журнал, установка** → [roles.md](roles.md) §5.3, [functional.md](functional.md) §6.8
- **SMTP / единый экран входа (2.59):** один контур «Вход» / «Регистрация» /
  «Не помню пароль»; сброс по логину или почте, письмо только на почту
  учётки; ссылка `#/auth/confirm?token=` (и код); без сессии до
  подтверждения; публичный URL писем — Admin → Установка; код/ссылка 30 мин
  → [functional.md](functional.md) §6.1.2
- **Уведомления о новых правках в очереди (почта / Telegram-канал)** → [user-settings.md](user-settings.md) §5.5.6, [functional.md](functional.md) §6.7
- **Вход с vsepsy.ru (та же почта и пароль)** → [vsepsy-identity.md](vsepsy-identity.md) §6.1.3

- **Личный граф** → `/my_graph` ([functional.md](functional.md) §6.5.1,

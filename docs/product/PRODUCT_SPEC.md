## 1. Назначение

Согласованное продуктовое ТЗ: для кого продукт, роли, функции, границы MVP,
критерии приёмки. Реализация и стек — не здесь (`MASTER_CONTEXT`, стадии).

## Куда смотреть по задаче

- **Локальный склад у нас** (ТЗ 2.61–2.63): GitHub, git, позже Dropbox / Google Drive — только **источники**. Продукт **копирует** `.md` в локальное хранилище (личное и опубликованная общая). Граф, карточки и Differ читают копию. → [vision.md](vision.md), [principles.md](principles.md) §3.1–3.4, [functional.md](functional.md) §6.2–6.3
- **ZIP загрузка (ТЗ 2.65):** до **10 000 файлов** в одном архиве (vault / git dump). ~120 файлов проходит. Свыше — HTTP 400, `archive has too many files`. Размер ZIP 2 МиБ / распаковка 8 МиБ / файл 256 КиБ и zip-бомба остаются. → [functional.md](functional.md) §6.3, [acceptance-and-nfr.md](acceptance-and-nfr.md) §9.1
- **Белый шум (ТЗ 2.67):** мусор (не заметки) в личном ingest не индексируется; учётка блокируется (`is_active`); admin’ам письмо. Настоящие уже проиндексированные заметки не удаляются. → [functional.md](functional.md) §6.3, [acceptance-and-nfr.md](acceptance-and-nfr.md) §9.1
- **Публикатор / плагин (ТЗ 2.68–2.76 / **2.82** / §6.3.4, §6.6.3):** человек через наше API кладёт **локальный граф в личное хранилище** — это **бесплатно** (не тариф Publish). Выбор карточек в плагине не обязателен: правки vault сами копируются в личное. В общую ризому плагин **не** публикует. Разговор о вкладе — **на сайте ризомы**: смотрим его склад; он сам предлагает что хочет через Differ; ризома может пометить его личные карточки, которых у нас нет («дай, если хочешь»), и предложить темы для новой карточки. В общую по-прежнему только Differ и очередь. → [functional.md](functional.md) §6.3.4, §6.6.3, [user-settings.md](user-settings.md) §5.5.7, [api.md](api.md)
- **Публикатор, карточка и боковой граф** (ТЗ 2.64): клик по узлу и `[[wikilink]]` открывают `/card/{путь}`; сбоку локальный граф. Гость читает опубликованную общую. → [search-and-card.md](search-and-card.md), [access.md](access.md) §5.6, [functional.md](functional.md) §6.5.1
- **Антипарсинг чтения общей (ТЗ 2.80 / §16):** один адрес → много разных карточек; доля корпуса; обход не по соседям; сначала 429, не вечный бан IP. **После выкатки на `rhizome`.** На `rhizome-test` не ставить. Капча на каждую карточку — нет. → [security.md](security.md)
- **Инвайты (ТЗ 2.84 / §17):** регистрация без инвайта невозможна. Инвайты раздаёт `admin`; свой инвайт — после **10 карточек, принятых editor’ом в общую**. Цепочка кто кого позвал. Гость без учётки читает общую. **После прода**, не тест. → [invites.md](invites.md)
- **Нет такой карточки (ТЗ 2.66):** гость — «карточки пока нет»; вошедший создаёт личную с этой страницы и из плашки при наведении на висячую ссылку. → [search-and-card.md](search-and-card.md)
- **Настройки аккаунта (`/user`), договор, свой git (опция), почта, Theme Switcher светлая/тёмная; имя / «Войти» в шапке не вплотную к рамке окна (ТЗ 2.77)** → [user-settings.md](user-settings.md)
- **«О программе» (`#/about`): титры ризомы и GraphNotes; подвал — только кнопка, без строки лицензий; договора на этой странице нет (ТЗ 2.78)** → [user-settings.md](user-settings.md) §5.5.8
- **Текст договора автора, лицензия карточек (WTFPL) и ПО (AGPL-3.0)** → [user-settings.md](user-settings.md) §5.5.3, [roles.md](roles.md) §5.4

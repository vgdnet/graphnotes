## 2. Видение продукта

GraphNotes — **публикатор Markdown с правами и одной общей ризомой**, в духе
[Obsidian Publish](https://publish.obsidian.md): у каждого свой граф своих
заметок, хостинг **у инсталляции**, не «знание живёт на GitHub». В отличие от
Publish здесь есть **доступ** (гость / сессия / автор / закрытый срез /
очередь editor’ов) и **ровно одна** общая ризома, которую группа editor’ов
собирает из личного слоя. Это не второй Obsidian (не live preview +
autocomplete `[[ ]]` + backlinks как продукт).

Основное хранилище личного знания — **локальный склад GraphNotes** этого
UUID (серверное личное хранилище; in-app редактор на сайте выключен, ТЗ 2.93,
пока нет обратной выгрузки в vault).
Внешние диски не живут рядом как второй канон: **GitHub**, git, позже
Dropbox / Google Drive — только **источники**. Продукт **копирует** `.md` в
локальный склад: личный слой и опубликованная общая ризома (ТЗ 2.63).
GitHub не витрина и не диск пользователя.

`/my_graph` — граф **этого** человека. `/graph` — опубликованная общая
ризома. Стартовая страница — граф общей, в том числе без входа: гость
открывает **карточки опубликованной общей** кликом по узлу или ссылке;
сбоку на карточке — локальный граф ([access.md](access.md) §5.6).
Опубликованную общую **нельзя скачать** файлами: нет ZIP, нет
«Скачать», нет продуктового clone корпуса. Чтение — в приложении.

Круговорот Markdown:

```text
локальный граф (плагин / API — бесплатно; или загрузка / git / другой коннектор)
  -> копия в личный склад GraphNotes
      -> на сайте ризома смотрит этот склад
          -> он сам предлагает что хочет
             или ризома помечает «у нас такой нет — дай, если хочешь»
             или предлагает темы для новой карточки
              -> Differ и предложение
                  -> очередь editor’ов
                      -> приняли в общую
                          -> Differ снова сравнил
                              -> авторский вклад в общей остаётся
```

Обратного пути «забрать общую файлами» нет. Личное остаётся у человека на
инсталляции (или в его git, если он так выбрал); общая читается в GraphNotes.

Положить локальный граф в личное через API/плагин — **бесплатно** (ТЗ 2.82).
Это не тариф Publish. Разговор о вкладе в общую — **на сайте ризомы**:
смотрим его склад; он предлагает что хочет; мы можем пометить карточки,
которых у нас нет, и предложить темы. В общую по-прежнему только Differ
и очередь; просьба ризомы не забирает карточку сама.

Ценность — живой граф, права, Differ и человеческая очередь слияния в одну
общую, не клон редактора и не обёртка над GitHub PR.

Следующая волна после успешной первой версии: **человек на общей ризоме**.
GraphNotes помнит не только текущий граф, но **историю взаимодействия с общей
ризомой**: кто создал карточку, кто поправил текст, кто поставил связь.
У автора и у editor есть **карточка пользователя** — публичный след вклада,
не GitHub-профиль.

Differ остаётся единственным путём личного → общее. Несколько editor’ов
разбирают много предложений; решение всегда за человеком. Подсказки
(в том числе будущая нейросеть) не принимают в общую сами.

Текст версий принятой в общую заметки — в общей ризоме (в текущем стеке
backend ещё может держать её git). GraphNotes не дублирует тела ради
«истории правок». Статистика и лента «кто что сделал с общей» живут в
продукте: из git log UUID автора не прочитать.

См. ADR-008 / ADR-009; **ТЗ 2.61** — склад у нас, не GitHub; **ТЗ 2.62** —
внешний диск копирует `.md` в локальный склад; **ТЗ 2.63** — GitHub тоже
только источник, в том числе для опубликованной общей. Leftover ADR-003:
merge editor’а ещё может пушить GitHub App, затем copy-in.

Инсталляция на **rhizome.vsepsy.ru** соседствует с базой психологов
**vsepsy.ru**: тот же человек входит той же почтой и паролем, каталог
специалистов в ризому не сливается (§6.1.3).

## 4. Термины

| Термин | Определение |
| --- | --- |
| Заметка | Markdown-файл и его индексированное представление |
| Узел | Производное представление заметки или unresolved-ссылки в графе |
| Связь | Производное направленное отношение между заметками из Markdown-ссылки |
| Личная база | Локальный склад GraphNotes (загрузки / in-app). Внешний диск копирует `.md` сюда, не второй канон. Производный граф — `/my_graph` |
| Индекс | Производные строки в PostgreSQL (`note_index` и связи) для поиска и графа. Не канон текста (ТЗ 2.63) |
| Выгрузка своей | Если есть — файлы с локального склада этого UUID. Не синтез из индекса. Общую так не отдают |
| Общая ризома | Единственное утвержденное коллективное Markdown-состояние одной инсталляции и его производный граф. Чтение в приложении, не «диск на GitHub» |
| Differ | Отдельная продуктовая сущность: одностороннее сравнение **текущего** личного хранилища с опубликованной общей ризомой и правила слияния выбранных отличий в общую |
| Авторский вклад | Заметки и связи, которые этот пользователь написал или ввёл: ещё только в личном складе, предложенные через Differ, принятые в общую |
| Provenance | Производная атрибуция узла или связи: автор (UUID GraphNotes), слой, revision, связь с предложением при наличии |
| Взаимодействие с общей | Событие на опубликованной общей ризоме: создана карточка, изменён текст, создана или снята связь, предложение рассмотрено. Не git log и не снимок текущего графа |
| Карточка пользователя | Страница человека в GraphNotes: `#/users/{uuid}` (ADR-012). Не `/user`. «Мой вклад» — `/contribution`. Публичные достижения: принятые карточки/связи, предложения, созданные в ризоме, правки в общей. `user` / `editor` / `автор` на одном UUID |
| Настройки | Экран учётки на `/user`: почта (обязательна), телефон и Telegram по желанию, свой git, договор автора. Имя в шапке открывает этот адрес. Не граф и не админка |
| Гость | Нет сессии: публичный холст `/graph` и поиск-подсветка. Страница карточки не открывается (§5.6, §6.5.2) |
| Карточка ризомы | Узел ризомы. На `/graph` — панель и ссылка вниз; отдельно — `/card/{путь}` с отрисованным Markdown. `/card` без пути — стартовая карточка из настроек admin (404 если не задана). Свою личную автор открывает на чтение и правит после «Отредактировать карточку»; общую, чужой личный и правку очереди — только просмотр. In-app правки своей карточки пишутся в ленту истории (без тел). Гостю страница не открывается |
| Поиск карточек | Поле на `/graph` (подсветка) и экран `/search` (каталог). Хит вошедшего — `/card/{путь}`. Ищет только видимый этому зрителю слой |
| VsePsy | Соседний продукт — база психологов на https://vsepsy.ru/. Не ризома |
| Связанная учётка vsepsy | Почта+пароль с vsepsy.ru открывают rhizome.vsepsy.ru без второй регистрации; роли каталога не копируются (§6.1.3) |
| Ачивка ризомы | Opt-in публичный кусок вклада (граф и/или счётчики) для vsepsy.ru и своего сайта; не ZIP; поля карточки всему интернету не зафиксированы (§6.1.4) |
| Уровень доступа к ризоме | Фильтр видимости среза одной ризомы: опубликованное / свой закрытый / чужой закрытый при entitlement. Не RBAC-роль (ADR-016) |
| Платный уровень доступа | Закрытый срез контента: тело видно автору, UUID с этим уровнем и `admin`; иначе замок. Шлюз оплаты только выдаёт уровень, не второе хранилище |
| Ризома автора | Вид закрытого среза после уровня доступа: граф и карточки только помеченных путей. Не вторая ризома, не второй git и не весь личный склад автора (§5.6.4) |
| Загрузить (закрытый срез) | Открыть вид «ризома автора» в GraphNotes после entitlement. Не скачать `.md` в vault / Obsidian и не ZIP/clone корпуса |
| Серверное личное хранилище | **Единственный** рабочий склад `.md` на стороне GraphNotes (ТЗ 2.62). Внешние диски копируют файлы сюда. На графе: **«ваша часть ризомы»** и **«ваша личная ризома»** (`/my_graph`) |
| Ваша часть ризомы | Overlay / пересечение: видимая общая страница плюс только те личные заметки, которые сами ссылаются на неё. Не весь личный склад. Слой считает индекс, не ручной список |
| Ваша личная ризома | Полный проиндексированный личный граф (`GET /api/graph/personal`): git или серверные загрузки. Карточки и поиск на этом слое — из этого дерева, не высыпание vault на общий граф |
| Загрузка без git | Копирование `.md`/ZIP в локальный склад. Git и другие коннекторы — тоже копирование сюда, не второй канон |
| История загрузок | Продуктовая лента: кто, когда, какие файлы, хеш содержимого, результат Differ/предложения. Не git log |
| Предложение | Git-backed заявка из выбранных результатов Differ в общую ризому, очередь editor’ов |
| Graph diff | Структурный вид Differ/предложения: добавленные, удаленные или измененные узлы и связи |
| Unresolved link | Ссылка на заметку, которой еще нет в выбранном состоянии |

# GraphNotes Publisher — плагин Obsidian

Desktop-версия 0.1.0: копирует локальный граф vault в **личное** хранилище GraphNotes (ТЗ 2.82). Это бесплатный вход публикатора, не тариф Obsidian Publish. Общая ризома не меняется: что отдать в общую — на сайте, через Differ.

## Установка для проверки

1. Создайте отдельное тестовое хранилище в Obsidian (desktop 1.8.7 или новее).
2. Распакуйте `graphnotes-publisher-0.1.0.zip`. Поместите папку `graphnotes-publisher` в `<хранилище>/.obsidian/plugins/`.
3. В папке должны лежать непосредственно `main.js`, `manifest.json`, `styles.css`.
4. Перезапустите Obsidian. В настройках → Сторонние плагины разрешите плагины и включите **GraphNotes Publisher**.
5. В настройках GraphNotes создайте токен с `personal:read` и `personal:write`. Для теста удаления добавьте `personal:delete`.
6. В настройках плагина укажите конечный адрес сервера (без `/api`), введите токен и нажмите «Проверить подключение».
7. Для тестового `http://172.16.13.14:8080` отдельно разрешите HTTP. API должен быть доступен через frontend reverse proxy; не требуется открывать backend в сеть.
8. Правки после сохранения уходят сами. Первая заливка уже существующего vault — «Отправить всё».

Токен берётся в GraphNotes: Настройки → Obsidian. Кабинет хранит ключ и снова показывает его, чтобы скопировать позже. Плагин помнит тот же ключ в `data.json`. Пароль учётки и обычная сессия сайта в плагин не вводятся. API должен быть доступен через frontend (`/api/…`).

## Поведение

- Правки в vault сами уходят в **личное** хранилище после сохранения (без выбора карточек и без экрана «что отправить»). Выбор карточек не обязателен.
- Первая заливка уже существующего vault — команда «Отправить всё». Совпавшие байты не передаются. Одновременно одна операция передачи.
- В общую ризому материал не попадает, предложение не создаётся, Differ не обходится.
- Поддерживаются `.md`, `.png`, `.jpg`, `.jpeg`, `.gif`, `.webp`, `.pdf`, если сервер объявил формат разрешённым.
- Конфликт (путь уже есть с другой версией): пакет не применяется. Человек смотрит серверный Markdown и явно подтверждает замену. Серверного `force=true` нет.
- Удаление на сервере — если у токена есть `personal:delete` и путь уже копировался. Локальное удаление без этого права серверный файл не стирает.
- Переименование — новый путь и отдельное удаление старого. Локальные файлы плагин не меняет.
- При обрыве связи: «Проверить / продолжить». Состав операции и токен сохраняются в `data.json`.
- Если байты ещё не загруженного файла изменились — план отменяется и готовится заново.
- Если сервер уже сохранил файлы, но индекс не готов, это видно отдельно; можно повторить индексацию.

## Данные и сеть

Для работы требуется аккаунт на выбранном сервере GraphNotes. Передаются новые и изменённые файлы, их относительные пути, хеши, размеры, технический ID подключения и удаления при наличии права. Манифест личных файлов читается для сравнения. Плагин не использует Obsidian Publish и не требует его подписки. Возможные тарифы сервера определяет его оператор.

Токен создаётся и хранится в кабинете GraphNotes (Настройки → Obsidian) и оттуда копируется в плагин. Плагин сохраняет тот же токен в `data.json`. Отозванный ключ писать не может; новый снова берётся в кабинете. Тел заметок в настройках нет. Соединение не следует HTTP-редиректам. Настройки TLS не ослабляются.

Нет клиентской телеметрии, доступа к файлам вне vault, исполнения кода заметок и самостоятельного обновления. Используется Node HTTP(S) исключительно на desktop, чтобы API не зависел от CORS и чтобы запретить перенаправления. Не является официальным продуктом Obsidian.

## Разработка

Node.js 22+, pnpm. Из этой папки:

```sh
pnpm install
pnpm build
pnpm test
```

Сборка: `dist/graphnotes-publisher/`. Установка зависимостей использует npm registry; runtime-зависимости не загружаются плагином. Основные модули: `core.ts` — сравнение; `sync.ts` — автокопирование vault; `api.ts` — контракт; `transport.ts` — сеть; `runner.ts` — восстановление; `main.ts` — интерфейс.

Согласование с серверным разработчиком: `API-HANDOFF.md`. Протокол проверок: `TESTING.md`.

## Границы этой версии

Мобильная версия, двусторонняя синхронизация и автоматическое слияние не реализованы. Одновременно выполняется одна операция. Максимальный размер пакета определяется API. Экран пометок ризомы «дай, если хочешь» и тем — на сайте, не в плагине. Windows/macOS и реальная интеграция проверяются пользователем отдельно; автоматические тесты не заменяют эти проверки.

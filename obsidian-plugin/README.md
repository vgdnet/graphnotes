# GraphNotes Publisher — плагин Obsidian

Desktop-версия 0.1.0 для ручной отправки выбранных заметок и вложений в **личное** хранилище GraphNotes. Общая ризома не меняется: предложение в неё делается отдельно через Differ.

## Установка для проверки

1. Создайте отдельное тестовое хранилище в Obsidian (desktop 1.8.7 или новее).
2. Распакуйте `graphnotes-publisher-0.1.0.zip`. Поместите папку `graphnotes-publisher` в `<хранилище>/.obsidian/plugins/`.
3. В папке должны лежать непосредственно `main.js`, `manifest.json`, `styles.css`.
4. Перезапустите Obsidian. В настройках → Сторонние плагины разрешите плагины и включите **GraphNotes Publisher**.
5. В настройках GraphNotes создайте токен с `personal:read` и `personal:write`. Для теста удаления добавьте `personal:delete`.
6. В настройках плагина укажите конечный адрес сервера (без `/api`), введите токен и нажмите «Проверить подключение».
7. Для тестового `http://172.16.13.14:8080` отдельно разрешите HTTP. API должен быть доступен через frontend reverse proxy; не требуется открывать backend в сеть.
8. Через значок отправки или палитру команд выполните «GraphNotes Publisher: Подготовить изменения». Выберите файлы/папку, выполните сверку, проверьте список и отправьте.

Токен берётся в GraphNotes: Настройки → Obsidian. Пароль учётки и обычная сессия сайта в плагин не вводятся. API должен быть доступен через frontend (`/api/…`).

## Поведение

- Изменения отправляются только по команде. Сохранение заметки не запускает сеть.
- Новые и изменённые выбранные файлы передаются целиком. Совпавшие не передаются.
- Вложения из Markdown/Obsidian-ссылок предлагаются в списке; связанные заметки автоматически не выбираются. Для анализа ссылок используется индекс Obsidian.
- Поддерживаются `.md`, `.png`, `.jpg`, `.jpeg`, `.gif`, `.webp`, `.pdf`, если сервер объявил формат разрешённым.
- Конфликты показываются явно. Можно посмотреть серверный Markdown или подтвердить замену. Сервер всё равно проверит версию.
- Удаления ранее отправленных файлов показываются отдельно и требуют подтверждения. Исключение из выбора не является удалением.
- Переименование — новый путь и отдельное удаление старого. Локальные файлы плагин не меняет.
- При обрыве связи откройте окно снова и нажмите «Проверить / продолжить». ID и состав операции сохраняются, токен — нет.
- Если байты ещё не загруженного файла после перезапуска изменились, отмените старый план и подготовьте новый.
- Если сервер уже сохранил файлы, но индекс не готов, плагин показывает это отдельно и позволяет проверить/повторить индексацию.

## Данные и сеть

Для работы требуется аккаунт на выбранном сервере GraphNotes. Передаются только выбранные файлы, их относительные пути, хеши, размеры, технический ID подключения и команды удаления, подтверждённые пользователем. Манифест личных файлов читается для сравнения. Плагин не использует Obsidian Publish и не требует его подписки. Возможные тарифы сервера определяет его оператор.

Токен создаётся один раз на сайте (как ключ SSH): сервер хранит только SHA-256 хеш, секрет больше не показывает. Плагин сохраняет секрет у себя (`data.json` плагина), чтобы не вставлять его после перезапуска Obsidian. Синхронизация настроек vault скопирует и его — как копирование приватного ключа. Тел заметок в настройках нет. Соединение не следует HTTP-редиректам. Настройки TLS не ослабляются.

Нет клиентской телеметрии, фоновой отправки, доступа к файлам вне vault, исполнения кода заметок и самостоятельного обновления. Используется Node HTTP(S) исключительно на desktop, чтобы API не зависел от CORS и чтобы запретить перенаправления. Не является официальным продуктом Obsidian.

## Разработка

Node.js 22+, pnpm. Из этой папки:

```sh
pnpm install
pnpm build
pnpm test
```

Сборка: `dist/graphnotes-publisher/`. Установка зависимостей использует npm registry; runtime-зависимости не загружаются плагином. Основные модули: `core.ts` — сравнение; `api.ts` — контракт; `transport.ts` — сеть; `runner.ts` — восстановление; `main.ts` — интерфейс.

Согласование с серверным разработчиком: `API-HANDOFF.md`. Протокол проверок: `TESTING.md`.

## Границы этой версии

Мобильная версия, двусторонняя синхронизация и автоматическое слияние не реализованы. Одновременно выполняется одна операция. Список выбора показывает до 500 совпадений; используйте фильтр или выбор папки для больших vault. Максимальный размер пакета определяется API. Windows/macOS и реальная интеграция проверяются пользователем отдельно; автоматические тесты не заменяют эти проверки.

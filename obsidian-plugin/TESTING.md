# Проверка плагина в Obsidian 1.13.7

Сервер и токен готовит агент API. Плагин только вызывает контракт из
`docs/deployment/OBSIDIAN_PLUGIN_API.md`.

Тестовый origin: `http://172.16.13.14:8080` (включить «Разрешить HTTP»).
Токен: сайт → Настройки → Obsidian, ключ `gnp_…` (хранится в кабинете, копируется сюда).

## Установка

1. `pnpm install && pnpm build` в этой папке.
2. Скопировать `dist/graphnotes-publisher/` в `<vault>/.obsidian/plugins/graphnotes-publisher/`.
3. Открыть отдельное хранилище (не рабочие `guide_psy` / `rhizome`).
4. Включить сторонние плагины и **GraphNotes Publisher**.

Готовый набор заметок: `test-vault/`.

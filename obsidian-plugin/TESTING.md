# Проверка плагина в Obsidian 1.13.7

Сервер и токен готовит агент API. Плагин только вызывает контракт из
`docs/deployment/OBSIDIAN_PLUGIN_API.md`.

Тестовый origin: `http://172.16.13.14:8080` (включить «Разрешить HTTP»).
Токен: сайт → Настройки → Obsidian, ключ `gnp_…` (хранится в кабинете, копируется сюда).

## Установка

1. `pnpm install && pnpm build` в этой папке.
2. Скопировать `dist/graphnotes-publisher/` в `<vault>/.obsidian/plugins/graphnotes-publisher/`.
3. Открыть отдельное хранилище (не рабочие `guide_psy` / `rhizome`).
4. Включить сторонние плагины и **GraphNotes Publisher**.

Готовый набор заметок: `test-vault/`.

## Сценарии

| ID | Что сделать | Ожидание |
| --- | --- | --- |
| T01 | Выбрать 3 файла из 10 | Уходят только отмеченные и явно оставленные вложения |
| T02 | Повторить без правок | Совпавшие не грузятся |
| T03 | Изменить один файл | Уходит только он |
| T04 | Поменять тот же путь в GraphNotes до commit | 409, пакет не применён |
| T05 | Первый путь уже есть на сервере | Конфликт, не затирает |
| T06 | Оборвать сеть после commit, затем «Проверить / продолжить» | Тот же результат, без двойной записи |
| T07 | Править файл во время отправки | Ушёл снимок; новое изменение остаётся в списке |
| T08 | Снять галочку / удалить локально | Исключение ≠ удаление; удаление с подтверждением |
| T09 | Переименовать | Новый путь + отдельное удаление старого |
| T17 | Заметка с картинкой и `[[wikilink]]` | Картинка предложена; вики-заметка не уходит сама |
| T18 | Сменить origin | Старый токен не уходит на новый адрес |

После успеха: ссылки «Личный граф» и «Differ» того же origin.
Общая ризома не меняется.
